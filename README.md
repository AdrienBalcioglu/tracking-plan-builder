# Tracking Plan Builder

Describe analytics events, enforce a naming convention and export the plan as CSV or JSON.

## Features

- Events with meaning, trigger, owner, status and typed properties
- Naming convention check: snake_case, Title Case or camelCase, plus duplicate detection
- CSV export for a spreadsheet, JSON export and import to version the plan
- Search across events

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build.

Your data is saved in the browser's local storage and never leaves your machine.

## Stack

HTML, CSS and JavaScript in a single file. No dependency.
